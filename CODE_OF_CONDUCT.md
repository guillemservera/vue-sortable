# Code of Conduct

We want VueSortable to be a welcoming, respectful and constructive project for everyone.

## Expected behavior

- Be respectful and assume good faith.
- Focus on the behavior and the technical problem, not the person.
- Give clear, actionable feedback.
- Accept that different approaches and experience levels exist.

## Unacceptable behavior

Harassment, discrimination, threats, personal attacks, doxxing, sexualized conduct, spam and deliberately disruptive behavior are not welcome.

## Enforcement

Report unacceptable behavior privately to [@guillemservera](https://github.com/guillemservera). Do not use public issues for sensitive reports. Security concerns should follow [SECURITY.md](SECURITY.md).

Project maintainers may remove comments, close discussions or restrict participation when necessary to keep the project safe and constructive.
