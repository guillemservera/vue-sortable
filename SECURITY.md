# Security Policy

## Supported versions

Only the latest published `0.x` release receives security fixes.

## Reporting a vulnerability

Please do not open a public issue for a security vulnerability. Use [GitHub's private vulnerability reporting](https://github.com/guillemservera/vue-sortable/security/advisories/new) when available.

If private reporting is unavailable, contact [@guillemservera](https://github.com/guillemservera) privately through GitHub. Include the affected version, a minimal reproduction, impact, and relevant environment details.

Please avoid including secrets or personal data in reports. Reports will be reviewed as soon as possible.
